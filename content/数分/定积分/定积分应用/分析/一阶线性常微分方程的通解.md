一阶线性 ODE 的标准形式为：$y' + c(x)y = f(x)$
- **核心公式**：
$$y = e^{-\int_a^x c(t)dt} \left( \int_a^x f(s) e^{\int_a^x c(t)dt} ds + y(a) \right)$$
（积分因子法，考虑$ye^{-\int_a^x c(t)dt}$的导数）

**证明：**
给定一阶线性常微分方程：
$$y' + c(x)y = f(x)$$
假设存在一个函数 $\mu(x) > 0$，我们在方程两边同乘 $\mu(x)$：
$$\mu(x)y' + \mu(x)c(x)y = \mu(x)f(x)$$
我们希望等式左边恰好是 $(\mu(x)y)'$ 的展开式。根据乘积法则求导：
$$(\mu(x)y)' = \mu(x)y' + \mu'(x)y$$
对比系数，要求等式成立，必须满足：
$$\mu'(x) = \mu(x)c(x)$$
这是一个可分离变量的微分方程，对其进行求解：
$$\frac{\mu'(x)}{\mu(x)} = c(x)$$
两边从 $a$ 到 $x$ 作定积分（使用变上限积分，引入哑变量 $t$）：
$$\int_a^x \frac{\mu'(t)}{\mu(t)} dt = \int_a^x c(t) dt$$
$$\ln \mu(x) - \ln \mu(a) = \int_a^x c(t) dt$$
为了简便，我们只需要找到_一个_满足条件的积分因子即可，不妨令 $\mu(a) = 1$（此时 $\ln \mu(a) = 0$），解得积分因子为：
$$\mu(x) = e^{\int_a^x c(t)dt}$$
将求得的积分因子 $\mu(x) = e^{\int_a^x c(t)dt}$ 乘回原方程的两边：
$$e^{\int_a^x c(t)dt} y' + c(x)e^{\int_a^x c(t)dt} y = f(x)e^{\int_a^x c(t)dt}$$
根据我们在第一步的构造，等式左边现在可以合并为一个全导数：
$$\frac{d}{dx} \left( y(x) e^{\int_a^x c(t)dt} \right) = f(x) e^{\int_a^x c(t)dt}$$
现在对上述等式两边同时从 $a$ 到 $x$ 作定积分（为避免符号混淆，积分变量用 $s$ 表示）：
$$\int_a^x \frac{d}{ds} \left( y(s) e^{\int_a^s c(t)dt} \right) ds = \int_a^x f(s) e^{\int_a^s c(t)dt} ds$$
对左边应用牛顿-莱布尼茨公式（微积分基本定理）：
$$\left[ y(s) e^{\int_a^s c(t)dt} \right]_{s=a}^{s=x} = \int_a^x f(s) e^{\int_a^s c(t)dt} ds$$
代入上下限 $x$ 和 $a$：
$$y(x) e^{\int_a^x c(t)dt} - y(a) e^{\int_a^a c(t)dt} = \int_a^x f(s) e^{\int_a^s c(t)dt} ds$$
由于 $\int_a^a c(t)dt = 0$，所以 $e^0 = 1$，左边第二项简化为 $y(a)$：
$$y(x) e^{\int_a^x c(t)dt} - y(a) = \int_a^x f(s) e^{\int_a^s c(t)dt} ds$$
最后，将 $-y(a)$ 移到等式右边，并在等式两边同乘 $e^{-\int_a^x c(t)dt}$ 以解出 $y(x)$：
$$y(x) e^{\int_a^x c(t)dt} = \int_a^x f(s) e^{\int_a^s c(t)dt} ds + y(a)$$
$$y(x) = e^{-\int_a^x c(t)dt} \left( \int_a^x f(s) e^{\int_a^s c(t)dt} ds + y(a) \right)$$
### 2. Gronwall 引理（不等式）

在常微分方程定性理论和偏微分方程先验估计中极其重要的工具。

- **核心公式（积分形式）**：假设 $u(t), \alpha(t), \beta(t)$ 为连续非负函数，且满足：
    
    $$u(t) \le \alpha(t) + \int_{t_0}^t \beta(s)u(s)ds$$
    
    若 $\alpha(t)$ 是非减常数，则：
    
    $$u(t) \le \alpha(t) e^{\int_{t_0}^t \beta(s)ds}$$
    
- **结构逻辑**：Gronwall 不等式的本质是**利用已知微分方程的解来控制未知函数**。考虑临界情况（等式成立时），它退化为一个齐次一阶线性方程 $u' = \beta(t)u$，其解含有指数项 $e^{\int \beta(s)ds}$。引理的证明通常也是通过构造辅助函数 $v(t) = \int_{t_0}^t \beta(s)u(s)ds$，对其求导并利用积分因子法求解。
    
- **应用场景**：常用于证明常微分方程解的唯一性（如 Picard-Lindelöf 定理）和解对初值的连续依赖性。
    

### 3. 积分型余项的 Taylor 公式

将函数在某一点展开为多项式与一个余项之和。

- **核心公式**：
    
    $$f(x) = \sum_{k=0}^n \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x)$$
    
    其中，积分型余项为：
    
    $$R_n(x) = \int_a^x \frac{f^{(n+1)}(t)}{n!}(x-t)^n dt$$
    
- **结构逻辑（分部积分迭代）**：相比于 Lagrange 或 Cauchy 余项依赖于中值定理（存在一个未知的中间点 $\xi$），积分型余项是**精确的等式**。它的推导起点是牛顿-莱布尼茨公式 $f(x) = f(a) + \int_a^x f'(t)dt$，然后对积分部分不断进行**分部积分**（Integration by Parts），人为引入因子 $(x-t)' = -1$ 逐步升阶。
    
- **优势**：条件更弱（仅要求 $f^{(n+1)}$ 黎曼可积，无需连续或存在更高阶导数），且在进行渐近分析或级数收敛性证明时，积分形式比带未知 $\xi$ 的微分形式更容易进行放缩估计。
    

### 4. 平面图形的面积

黎曼积分最基础的几何意义。

- **核心公式**：
    
    - 直角坐标系下（上下边界为 $f(x)$ 和 $g(x)$）：$A = \int_a^b |f(x) - g(x)| dx$
        
    - 极坐标系下（曲线 $r=r(\theta)$）：$A = \frac{1}{2} \int_\alpha^\beta r^2(\theta) d\theta$
        
- **结构逻辑**：其本质是测度论在二维空间的体现。直角坐标利用的是细分矩形（$dA = y\,dx$），极坐标利用的是细分扇形（$dA = \frac{1}{2}r \cdot (r d\theta)$）。黎曼和（或 Darboux 和）通过对微元面积的极限求和，将二维的面积问题降维转化为一维定积分。
    

### 5. 平面曲线的弧长

衡量曲折路径长度的工具。

- **核心公式（参数方程形式）**：若曲线由 $x=x(t), y=y(t)$ 给出，则弧长为：
    
    $$s = \int_\alpha^\beta \sqrt{(x'(t))^2 + (y'(t))^2} dt$$
    
- **结构逻辑（微观勾股定理）**：弧长积分的微元 $ds$ 本质上是欧几里得空间度量 $ds^2 = dx^2 + dy^2$ 的体现。在宏观上，它是折线逼近曲线求极限的结果；在微观上，它是在切线方向上利用勾股定理求微小斜边的长度。后续的直角坐标形式和极坐标形式均可由此参数方程形式通过变量代换推导得出。
    

### 6. 已知平行截面面积函数的立体体积

计算非规则三维物体的体积。

- **核心公式**：若立体在 $x$ 轴的投影区间为 $[a, b]$，且垂直于 $x$ 轴的截面面积为已知的 $A(x)$，则：
    
    $$V = \int_a^b A(x) dx$$
    
- **结构逻辑（祖暅原理/Cavalieri原理）**：这实际上是 Fubini 定理在三维空间的特例，即三重积分化为累次积分。体积微元 $dV = A(x)dx$ 可以理解为厚度极薄的柱体。只要知道每个“切片”的面积，无需关心切片的具体形状，沿着垂直方向积分即可得到总体积。
    

### 7. 旋转体的侧面积

平面曲线绕某一坐标轴旋转一周扫过的曲面面积。

- **核心公式**（以曲线 $y=f(x)$ 绕 $x$ 轴旋转为例）：
    
    $$S = \int_a^b 2\pi |y| ds = \int_a^b 2\pi |f(x)| \sqrt{1 + (f'(x))^2} dx$$
