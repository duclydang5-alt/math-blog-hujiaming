> [!tip] 三弦引理
> 假设 $f(x)$ 是区间 $I$ 上的凸函数。对于区间内的任意三个点 $x_1 < x_2 < x_3$，凸函数的定义价于以下割线斜率的单调不等式：$$ \frac{f(x_2) - f(x_1)}{x_2 - x_1} \le \frac{f(x_3) - f(x_1)}{x_3 - x_1} \le \frac{f(x_3) - f(x_2)}{x_3 - x_2} $$

证明：

因为 $x_2$ 严格位于 $x_1$ 和 $x_3$ 之间，必然存在一个参数 $t \in (0, 1)$，使得 $x_2$ 可以写成 $x_1$ 和 $x_3$ 的加权平均：

$$x_2 = t x_1 + (1 - t) x_3$$

解出参数 $t$ 和 $1-t$：
 $$t(x_3 - x_1) = x_3 - x_2 \implies t = \frac{x_3 - x_2}{x_3 - x_1}$$

$$1 - t = 1 - \frac{x_3 - x_2}{x_3 - x_1} = \frac{x_2 - x_1}{x_3 - x_1}$$

根据凸函数的定义，对于任意 $t \in (0, 1)$，有：

$$f(tx_1 + (1-t)x_3) \le t f(x_1) + (1-t) f(x_3)$$

将 $x_2$ 及其对应的 $t$ 和 $1-t$ 的表达式代入上式：

$$f(x_2) \le \frac{x_3 - x_2}{x_3 - x_1} f(x_1) + \frac{x_2 - x_1}{x_3 - x_1} f(x_3)$$

为了消除分母，两边同乘正数 $(x_3 - x_1)$，得到**主不等式**：

$$(x_3 - x_1)f(x_2) \le (x_3 - x_2)f(x_1) + (x_2 - x_1)f(x_3)$$

接下来的所有结论都通过对这个主不等式进行代数重组得到。

---

### 3. 证明左半部分：斜率 $(x_1, x_2) \le$ 斜率 $(x_1, x_3)$

目标是构造出 $f(x_2) - f(x_1)$。我们在主不等式两边同时减去 $(x_3 - x_1)f(x_1)$：

$$(x_3 - x_1)f(x_2) - (x_3 - x_1)f(x_1) \le (x_3 - x_2)f(x_1) - (x_3 - x_1)f(x_1) + (x_2 - x_1)f(x_3)$$

提取公因式并化简右侧：

- 左侧：$(x_3 - x_1)(f(x_2) - f(x_1))$
    
- 右侧合并 $f(x_1)$ 项：$[(x_3 - x_2) - (x_3 - x_1)] f(x_1) = -(x_2 - x_1)f(x_1)$
    
- 右侧整体变为：$(x_2 - x_1)f(x_3) - (x_2 - x_1)f(x_1) = (x_2 - x_1)(f(x_3) - f(x_1))$
    

于是得到：

$$(x_3 - x_1)(f(x_2) - f(x_1)) \le (x_2 - x_1)(f(x_3) - f(x_1))$$

两边同除以正数 $(x_3 - x_1)(x_2 - x_1)$，即证得左半部分：

$$\frac{f(x_2) - f(x_1)}{x_2 - x_1} \le \frac{f(x_3) - f(x_1)}{x_3 - x_1}$$

---

### 4. 证明右半部分：斜率 $(x_1, x_3) \le$ 斜率 $(x_2, x_3)$

目标是构造出 $f(x_3) - f(x_2)$。我们在主不等式两边同时减去 $(x_3 - x_1)f(x_3)$：

$$(x_3 - x_1)f(x_2) - (x_3 - x_1)f(x_3) \le (x_3 - x_2)f(x_1) + (x_2 - x_1)f(x_3) - (x_3 - x_1)f(x_3)$$

同样提取公因式并化简：

- 左侧：$-(x_3 - x_1)(f(x_3) - f(x_2))$
    
- 右侧合并 $f(x_3)$ 项：$[(x_2 - x_1) - (x_3 - x_1)] f(x_3) = -(x_3 - x_2)f(x_3)$
    
- 右侧整体变为：$(x_3 - x_2)f(x_1) - (x_3 - x_2)f(x_3) = -(x_3 - x_2)(f(x_3) - f(x_1))$
    

于是得到：

$$-(x_3 - x_1)(f(x_3) - f(x_2)) \le -(x_3 - x_2)(f(x_3) - f(x_1))$$

两边同乘 $-1$（**不等号变号**）：

$$(x_3 - x_1)(f(x_3) - f(x_2)) \ge (x_3 - x_2)(f(x_3) - f(x_1))$$

两边同除以正数 $(x_3 - x_1)(x_3 - x_2)$，即证得右半部分：

$$\frac{f(x_3) - f(x_2)}{x_3 - x_2} \ge \frac{f(x_3) - f(x_1)}{x_3 - x_1}$$

至此，三弦引理的链式不等式证明完毕。
