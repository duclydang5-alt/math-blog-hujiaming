### 第一部分，拓展至 $2^k$ 个变量

已知中点凸定义：对于任意 $x_1, x_2$，有 $f\left(\frac{x_1+x_2}{2}\right) \le \frac{f(x_1)+f(x_2)}{2}$。
我们的目标是证明对于任意 $k \in \mathbb{N}^+$，均有：

$$f\left(\frac{1}{2^k}\sum_{i=1}^{2^k} x_i\right) \le \frac{1}{2^k}\sum_{i=1}^{2^k} f(x_i)$$
**证明**：对 $k$ 使用数学归纳法

$k=1$ 时，即为中点凸定义，显然成立。

假设对 $k$ 成立，当变量个数为 $2^{k+1}$ 时，我们将这 $2^{k+1}$ 个变量均分为两组，每组 $2^k$ 个，并利用中点凸性质：

$$f\left(\frac{1}{2^{k+1}}\sum_{i=1}^{2^{k+1}} x_i\right) = f\left( \frac{ \frac{1}{2^k}\sum_{i=1}^{2^k} x_i + \frac{1}{2^k}\sum_{i=2^k+1}^{2^{k+1}} x_i }{2} \right)$$

应用 $k=1$ 的中点凸：

$$\le \frac{1}{2} \left[ f\left(\frac{1}{2^k}\sum_{i=1}^{2^k} x_i\right) + f\left(\frac{1}{2^k}\sum_{i=2^k+1}^{2^{k+1}} x_i\right) \right]$$

再分别对括号内的两项应用归纳假设（$k$ 的情况）：

$$\le \frac{1}{2} \left[ \frac{1}{2^k}\sum_{i=1}^{2^k} f(x_i) + \frac{1}{2^k}\sum_{i=2^k+1}^{2^{k+1}} f(x_i) \right] = \frac{1}{2^{k+1}}\sum_{i=1}^{2^{k+1}} f(x_i)$$

至此，正向倍增完成


### 第二部分，反向归纳（回退至任意正整数 $n$）

目标是证明对于任意正整数 $n$，离散形式的 Jensen 不等式成立：

$$f\left(\frac{x_1 + x_2 + \dots + x_n}{n}\right) \le \frac{f(x_1) + f(x_2) + \dots + f(x_n)}{n}$$

**证明**：

任取正整数 $n$，必然存在一个整数 $k$，使得 $2^k > n$。令 $m = 2^k$。

构造一个“均值填充”**：设前 $n$ 个变量的算术平均数为 $A = \frac{1}{n}\sum_{i=1}^n x_i$。

我们将剩下的 $m-n$ 个变量全部取值为 $A$，即令 $x_{n+1} = x_{n+2} = \dots = x_m = A$。

此时，这 $m$ 个变量的总和为：

$$\sum_{i=1}^n x_i + (m-n)A = nA + (m-n)A = mA$$

这意味着这 $m$ 个变量的平均数依然是 $A$

现在，对这 $m$（即 $2^k$）个变量应用阶段一的结论：

$$f\left(\frac{mA}{m}\right) \le \frac{1}{m} \left[ \sum_{i=1}^n f(x_i) + \sum_{i=n+1}^m f(A) \right]$$

即：

$$f(A) \le \frac{1}{m} \left[ \sum_{i=1}^n f(x_i) + (m-n)f(A) \right]$$

两边同乘 $m$：

$$mf(A) \le \sum_{i=1}^n f(x_i) + mf(A) - nf(A)$$

消去两边的 $mf(A)$ 并移项：

$$nf(A) \le \sum_{i=1}^n f(x_i) \implies f(A) \le \frac{1}{n}\sum_{i=1}^n f(x_i)$$

将 $A$ 的定义代入，即得证任意 $n$ 个变量的均值凸性


### 第三部分：降维映射（转化为有理数权重）

目标是证明对于任意有理数 $t \in (0, 1)$，有 $f(tx + (1-t)y) \le tf(x) + (1-t)f(y)$

**证明**：

既然 $t$ 是有理数，它可以表示为两个正整数的商：$t = \frac{p}{q}$，其中 $p, q \in \mathbb{N}^+$ 且 $p < q$。

同时 $1-t = \frac{q-p}{q}$。

现在，我们直接利用阶段二中证明的 $n$ 变量 Jensen 不等式，令 $n = q$。

在这 $q$ 个变量中，我们让前 $p$ 个变量全部等于 $x$，后 $q-p$ 个变量全部等于 $y$。

将其代入阶段二的公式：

$$f\left( \frac{\overbrace{x + \dots + x}^{p\text{ 个}} + \overbrace{y + \dots + y}^{q-p\text{ 个}}}{q} \right) \le \frac{\overbrace{f(x) + \dots + f(x)}^{p\text{ 个}} + \overbrace{f(y) + \dots + f(y)}^{q-p\text{ 个}}}{q}$$

化简上述等式：

$$f\left( \frac{p}{q}x + \frac{q-p}{q}y \right) \le \frac{p}{q}f(x) + \frac{q-p}{q}f(y)$$

将 $t = \frac{p}{q}$ 代回，即得到最终结论：

$$f(tx + (1-t)y) \le tf(x) + (1-t)f(y) \quad (\forall t \in \mathbb{Q} \cap [0,1])$$

但对于标准凸，我们就无法在这个方法下继续精进了，因为标准凸的系数中包含无理数，而无理数是无法被如上的分数表示的，接下来的推广由[[3Bernstein-Doetsch 定理]]给出
