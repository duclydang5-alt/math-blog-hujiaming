### 平凡的常识

1. $\mathbf{F}^n = \{(a_1, a_2, \cdots, a_n)^{\mathrm{T}} \mid a_i \in \mathbf{F}\}$ 关于向量的加法和数乘构成线性空间，具体展开而言便是 $\forall (a_1, a_2, \cdots, a_n)^{\mathrm{T}}, (b_1, b_2, \cdots, b_n)^{\mathrm{T}} \in \mathbf{F}^n$，$\forall \lambda \in \mathbf{F}$，有

$$(a_1, a_2, \cdots, a_n)^{\mathrm{T}} + (b_1, b_2, \cdots, b_n)^{\mathrm{T}} = (a_1 + b_1, a_2 + b_2, \cdots, a_n + b_n)^{\mathrm{T}},$$

$$\lambda(a_1, a_2, \cdots, a_n)^{\mathrm{T}} = (\lambda a_1, \lambda a_2, \cdots, \lambda a_n)^{\mathrm{T}}.$$

2. $\mathbf{F}[x]_{n+1} = \{a_0 + a_1 x + \cdots + a_n x^n \mid a_i \in \mathbf{F}\}$ 关于多项式的加法和数乘构成线性空间，具体展开而言便是

$$(p_1 + p_2)(x) = p_1(x) + p_2(x), \quad (\lambda p)(x) = \lambda p(x), \quad \forall p_1, p_2, p \in \mathbf{F}[x]_{n+1}, \forall \lambda \in \mathbf{F}.$$

这也能解释常见记号的含义：$(k_1 p_1 + k_2 p_2)(x) = k_1 p_1(x) + k_2 p_2(x)$

但我们需要注意 $\mathbf{F}[x]'_{n+1} = \{a_0 + a_1 x + \cdots + a_n x^n \mid a_i \in \mathbf{F}, a_n \neq 0\}$ 不构成线性空间.

不构成线性空间，其原因在于我们加法不封闭，例如我们取 $\mathbf{F}[x]'_{n+1}$ 中的两个元素 $x^n$ 和 $-x^n$，它们的和为 $0$，不再满足 $\mathbf{F}[x]'_{n+1}$ 中关于 $a_n \neq 0$ 的条件，因此运算不封闭，不构成线性空间

这里可见，多项式函数之所以能够作为一个线性空间，是因为不定元充当了指标序，将多项式同构成了普通的向量

### 抽象的向量组成的线性空间

1. 设 $V = C[a, b]$ 为定义在闭区间 $[a, b]$ 上的连续实值函数全体，定义 $V(\mathbf{R})$，其中加法运算定义为
$$(f + g)(x) = f(x) + g(x), \quad \forall f, g \in C[a, b].$$
数乘运算定义为
$$(\lambda f)(x) = \lambda f(x), \quad \forall f \in C[a, b],\ \forall \lambda \in \mathbf{R}.$$
则 $C[a, b]$ 构成实数域上的线性空间.

2. 设 $V$ 是以 $0$ 为极限的实数数列全体，定义 $V(\mathbf{R})$，其中两个数列的加法和数乘定义为
$$\{a_n\} + \{b_n\} = \{a_n + b_n\}, \quad \lambda\{a_n\} = \{\lambda a_n\}, \quad \forall \{a_n\}, \{b_n\} \in V,\ \forall \lambda \in \mathbf{R}$$
则V构成实数域上的线性空间.

### 抽象的数乘组成的线性空间

$\mathbf{C}(\mathbf{R})$ 是群 $\langle \mathbf{C}; + \rangle$，此处也不再验证. 因此这里只验证 $\mathbf{C}(\mathbf{R})$ 数乘运算是否满足线性空间定义的要求：

1. 取定 $1 \in \mathbf{R}, \forall \alpha = a + b\mathrm{i} \in \mathbf{C},\ a, b \in \mathbf{R},\ 1 \cdot \alpha = 1 \cdot (a + b\mathrm{i}) = a + b\mathrm{i} = \alpha.$
2. $\forall \lambda, \mu \in \mathbf{R},\ \alpha = a + b\mathrm{i} \in \mathbf{C},\ a, b \in \mathbf{R}$,
$$\lambda(\mu\alpha) = \lambda(\mu(a + b\mathrm{i})) = \lambda(\mu a + \mu b\mathrm{i}) = \lambda\mu a + \lambda\mu b\mathrm{i} = (\lambda\mu)(a + b\mathrm{i}) = (\lambda\mu)\alpha.$$
3. $\forall \lambda, \mu \in \mathbf{R},\ \alpha = a + b\mathrm{i} \in \mathbf{C},\ a, b \in \mathbf{R}$,
$$(\lambda + \mu)\alpha = (\lambda a + \lambda b\mathrm{i}) + (\mu a + \mu b\mathrm{i})$$
$$= \lambda(a + b\mathrm{i}) + \mu(a + b\mathrm{i}) = \lambda\alpha + \mu\alpha.$$
4. $\forall \lambda \in \mathbf{R},\ \alpha_1 = a_1 + b_1\mathrm{i}, \alpha_2 = a_2 + b_2\mathrm{i} \in \mathbf{C},\ a_i, b_i \in \mathbf{R},\ i = 1, 2$,
$$\lambda(\alpha_1 + \alpha_2) = \lambda((a_1 + b_1\mathrm{i}) + (a_2 + b_2\mathrm{i})) = \lambda((a_1 + a_2) + (b_1 + b_2)\mathrm{i})$$
$$= \lambda(a_1 + a_2) + \lambda(b_1 + b_2)\mathrm{i} = (\lambda a_1 + \lambda b_1\mathrm{i}) + (\lambda a_2 + \lambda b_2\mathrm{i})$$
$$= \lambda(a_1 + b_1\mathrm{i}) + \lambda(a_2 + b_2\mathrm{i}) = \lambda\alpha_1 + \lambda\alpha_2$$
由此我们证明了 $\mathbf{C}(\mathbf{R})$ 构成线性空间


### 抽象的运算组成的线性空间

$V$ 是正实数全体 $\mathbf{R}^+$，定义 $V(\mathbf{R})$ 上的加法和数乘为

$$a \oplus b = ab$$
$$\lambda \circ a = a^\lambda$$

则如上定义的 $V(\mathbf{R})$ 是 $\mathbf{R}$ 上的线性空间

#### 同构的引入
我们可以定义映射 $\varphi: \mathbf{R} \to \mathbf{R}^+$，其中 $\phi(x) = e^x$，则 $\varphi$ 是一个双射（这是一个有反函数 $\ln x$ 的可逆映射）事实上两个集合中所有元素都可以两两凑对（例如 $(1, e)$ 也能凑对，可以记为 $(a, \varphi(a))$），这就是双射“一一对应”的意义.

除此之外，映射 $\varphi$ 还有另一个重要的性质. 我们不难发现，
$$\varphi(x + y) = e^{x+y} = e^x \cdot e^y = \varphi(x) \oplus \varphi(y), \quad \forall x, y \in \mathbf{R}$$
$$\varphi(\lambda x) = e^{\lambda x} = (e^x)^\lambda = \lambda \circ \varphi(x), \quad \forall x, \lambda \in \mathbf{R}$$
经过某个函数后，两个线性空间可以这样形成一一对应的话，我们可以通过研究与B同构的A来间接地研究B，后续给出[[3同态与同构]]的详细定义
