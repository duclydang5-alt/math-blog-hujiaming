### 1. 互余关系

- **正余弦互余：** $\arcsin x + \arccos x = \frac{\pi}{2}$ （定义域：$x \in [-1, 1]$）
- **正余切互余：** $\arctan x + \text{arccot } x = \frac{\pi}{2}$ （定义域：$x \in \mathbb{R}$）
- **正余割互余：** $\text{arcsec } x + \text{arccsc } x = \frac{\pi}{2}$ （定义域：$|x| \ge 1$）


> **实战意义：** 当你在积分里看到 $\arccos x$ 觉得不好处理时，可以直接用 $\frac{\pi}{2} - \arcsin x$ 替换，往往能与题目中的其他项抵消。

### 2. 负角关系（奇偶性）

了解函数的奇偶性，对于处理积分区间对称的问题（如 $\int_{-a}^a f(x) dx$）至关重要

- **奇函数（直接把负号提出来）：**
- $\arcsin(-x) = -\arcsin x$
- $\arctan(-x) = -\arctan x$
- **非奇非偶（需要用 $\pi$ 来补足）：**
- $\arccos(-x) = \pi - \arccos x$


### 3. 倒数关系（翻转参数）

当被积函数或方程中同时出现 $x$ 和 $\frac{1}{x}$ 时，这组公式是破局的关键

- $\arcsin(\frac{1}{x}) = \text{arccsc } x$
- $\arccos(\frac{1}{x}) = \text{arcsec } x$

**特别注意正切的倒数（有象限陷阱）：**
- 当 $x > 0$ 时：$\arctan(\frac{1}{x}) = \text{arccot } x = \frac{\pi}{2} - \arctan x$
- 当 $x < 0$ 时：$\arctan(\frac{1}{x}) = -\frac{\pi}{2} - \arctan x$

### 4. 加减法恒等式（“重武器”）

这是由正切的加法公式 $\tan(\alpha \pm \beta) = \frac{\tan \alpha \pm \tan \beta}{1 \mp \tan \alpha \tan \beta}$ 逆推过来的

- **加法：** $\arctan x + \arctan y = \arctan\left(\frac{x+y}{1-xy}\right)$ （条件：$xy < 1$）
- **减法：** $\arctan x - \arctan y = \arctan\left(\frac{x-y}{1+xy}\right)$ （条件：$x > 0$ 且 $y > 0$ 适用性最强）


 **回顾上一题：** 我们在上一题用到的神仙代换 $\arctan\left(\frac{1-t}{1+t}\right)$，其实就是利用了减法公式：
$$\arctan\left(\frac{1-t}{1+1 \cdot t}\right) = \arctan 1 - \arctan t = \frac{\pi}{4} - \arctan t$$
以后再碰到 $\frac{a-x}{1+ax}$ 这种结构，要形成条件反射
$$\arctan\left(\frac{a-t}{1+a \cdot t}\right) = \arctan a - \arctan t$$

### 5. 跨函数转换

1. 设 $\theta = \arcsin x$。这意味着在一个直角三角形中，对边是 $x$，斜边是 $1$。
2. 用勾股定理求出邻边：$\sqrt{1 - x^2}$
3. 现在你可以看图写出任何其他的三角函数：
- $\tan \theta = \frac{\text{对边}}{\text{邻边}} = \frac{x}{\sqrt{1-x^2}}$，所以 $\arcsin x = \arctan\left(\frac{x}{\sqrt{1-x^2}}\right)$。
- $\cos \theta = \frac{\text{邻边}}{\text{斜边}} = \sqrt{1-x^2}$，所以 $\arcsin x = \arccos\left(\sqrt{1-x^2}\right)$。
